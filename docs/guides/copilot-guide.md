# GitHub Copilot Guide

1. Open the repository root in VS Code.
2. Use Copilot Chat in Agent mode where supported.
3. Ensure `.github/copilot-instructions.md` is in scope.
4. Select the QE Orchestrator custom agent for multi-step tasks.
5. Refer to skills by name, for example `qe-orchestration` or `playwright-automation`.
6. Inspect all generated changes and command proposals.
7. Keep execution approval separate from code-generation approval.

Feature names and discovery behavior can vary by Copilot version; check the installed version's current documentation.
