# Playwright Standards

- Prefer accessible locators: role, label, placeholder and test id.
- Use web-first assertions and built-in auto-waiting.
- Avoid fixed sleeps and fragile selectors.
- Isolate tests and use fixtures for setup and teardown.
- Use API setup where it makes UI tests faster and more deterministic, while still validating the UI behavior.
- Capture traces and screenshots on failure.
- Use explicit base URLs and approved test accounts.
- Never run against production without explicit authorization.
