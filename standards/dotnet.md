# C# / .NET Standards

- Follow the solution's target framework and existing conventions.
- Enable nullable reference types where supported by project policy.
- Keep test setup explicit and deterministic.
- Use async/await end-to-end for asynchronous APIs.
- Dispose streams, clients and other disposable resources correctly.
- Avoid static mutable state in tests.
- Keep assertions focused and diagnostics actionable.
- Do not upgrade SDKs or packages without assessing compatibility.
