# Pull Request Quality Review — MCP Prompt

Use GitHub MCP in read-only mode. Inspect only the named repository and pull request.

Review:
- Scope and requirement traceability
- Changed code and potential regressions
- Automated test coverage and missing scenarios
- GitHub Actions evidence
- Security, secrets and dependency risks
- Maintainability and observability

Return findings with file/line references where available, severity and suggested fix. Do not submit a review, approve, request changes, create a branch, push, or merge.
