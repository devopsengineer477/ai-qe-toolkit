# Requirement to Test Design — MCP Prompt

Use the QE Orchestrator. Use Atlassian MCP only to read the explicitly named Jira issue(s) and approved Confluence space(s). Do not search unrelated projects or spaces.

1. Summarize requirements and acceptance criteria with issue/page identifiers.
2. Identify ambiguity, dependencies and risks.
3. Map each requirement to positive, negative, boundary, authorization and regression scenarios as appropriate.
4. Produce a traceability matrix and test data needs.
5. Cite source identifiers for each extracted requirement.
6. Do not create or modify Jira/Confluence content, call application APIs, or run tests.
